## Get up and running in three steps

Follow these steps to go from zero to your first confirmed seat reservation.

<Steps>
  <Step title="Run the application">
    Open `JordiAragonZaragoza.Cinema.sln` in Visual Studio 2022 and press **F5**, or run `dotnet run` from the solution root. .NET Aspire orchestrates every service — the Command API, Query API, Kurrent DB event store, and PostgreSQL projection store — with a single launch.
  </Step>
  <Step title="Obtain a JWT token">
    Send a `POST` request to `/api/v2/auth/login` with your credentials. Copy the `accessToken` from the response and include it as a `Bearer` token in the `Authorization` header of every subsequent call.
  </Step>
  <Step title="Make your first reservation">
    Call `POST /api/v2/showtimes/{showtimeId}/reservations` with the seat numbers you want. The API returns a reservation GUID, the confirmed seat numbers, auditorium details, and movie information. You have **one minute** to purchase the reservation before it expires.
  </Step>
</Steps>
