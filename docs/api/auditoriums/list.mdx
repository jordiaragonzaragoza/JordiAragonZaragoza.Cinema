Use this endpoint to retrieve every auditorium configured in the system. The response includes each auditorium's name and total seat capacity, giving you a quick overview of available screening spaces. Use the returned `auditoriumId` values when scheduling new showtimes or when fetching the full row-by-row seat layout for a specific auditorium.

## Endpoint

```
GET https://your-cinema-api.com/api/v2/auditoriums
```

## Request

This endpoint requires no query parameters. Include your Bearer token in the `Authorization` header with every request.

```bash
curl --request GET \
  --url https://your-cinema-api.com/api/v2/auditoriums \
  --header "Authorization: Bearer <token>"
```

## Response

### 200 — Success

Returns a JSON array of auditorium objects.

<ResponseField name="auditoriumId" type="string (GUID)" required>
  The unique identifier for this auditorium. Pass this value to [Get Auditorium Details](/api/auditoriums/get) to retrieve the full seat layout, or use it when [scheduling a showtime](/api/showtimes/schedule).
</ResponseField>

<ResponseField name="name" type="string" required>
  The human-readable display name of the auditorium (e.g. `"Auditorium 1"`).
</ResponseField>

<ResponseField name="totalSeats" type="integer" required>
  The total number of seats in this auditorium across all rows.
</ResponseField>

**Example response**

```json
[
  {
    "auditoriumId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "name": "Auditorium 1",
    "totalSeats": 150
  },
  {
    "auditoriumId": "b2c3d4e5-f6a7-8901-bcde-f12345678901",
    "name": "Auditorium 2",
    "totalSeats": 200
  }
]
```

## Error Codes

| Status | Meaning | Description |
|--------|---------|-------------|
| `401`  | Unauthorized | Your Bearer token is missing or invalid. Verify that you are sending a valid `Authorization` header. |

**Example error response**

```json
{
  "type": "https://tools.ietf.org/html/rfc7235#section-3.1",
  "title": "Unauthorized",
  "status": 401,
  "detail": "Authentication token is missing or invalid."
}
```
